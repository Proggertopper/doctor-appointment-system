Політика обробки персональних даних

Ця політика пояснює, які персональні дані можуть збиратися під час онлайн-запису на прийом до лікаря, з якою метою вони використовуються та як захищаються.

1. Які дані ми збираємо

Під час запису на прийом користувач може надати такі дані:

  • ім’я;
  • номер телефону;
  • обрані дата, час та формат прийому;
  • коментар до запису, якщо користувач його залишає.

2. Мета обробки даних

Персональні дані використовуються виключно для організації запису на прийом, підтвердження запису, зв’язку з пацієнтом та можливості скасування запису.

3. SMS-повідомлення

Номер телефону використовується для відправлення SMS-коду підтвердження, а також для повідомлення з деталями запису та посиланням для скасування запису.

4. Зберігання даних

Дані зберігаються в системі запису до лікаря та використовуються тільки для цілей, пов’язаних із прийомом пацієнта.

5. Передача даних третім особам

Персональні дані не передаються стороннім особам, окрім випадків, необхідних для технічної відправки SMS-повідомлень або передбачених законом.

6. Права користувача

Користувач може скасувати свій запис за посиланням із SMS-повідомлення. Також користувач може звернутися до лікаря для уточнення або видалення своїх даних, якщо це не суперечить законним вимогам.

7. Згода користувача

Надсилаючи форму запису, користувач підтверджує, що ознайомився з цією політикою та погоджується на обробку персональних даних для запису на прийом.
